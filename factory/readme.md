# 🏭 MES 智慧工廠監控系統 (Smart Factory Simulation)

這是一個基於 **JavaScript** 實作的輕量化製造執行系統（MES）模擬器。它模擬了真實工廠環境中的生產線邏輯，包含智慧派工、機台故障維修機制、以及視覺化的即時監控看板。

---

## ✨ 核心功能

### 1. 智慧派工大腦 (Dispatching Logic)
系統採用動態調度演算法，確保生產效率最大化：
*   **老鳥優先 (WIP First)**：優先處理半成品緩衝區（Buffer）的物件，減少在製品堆積。
*   **急單優先 (Priority-based)**：自動根據產品優先級（Priority 1 最急）進行排序，確保特急件優先上機。

### 2. 模擬真實異常 (Machine Behavior)
*   **隨機故障 (Down Time)**：機台在運作中具有隨機故障機率，模擬真實設備的不確定性。
*   **固定維修工時 (MTTR)**：一旦故障，系統將進入固定維修倒數，期間停止所有加工任務。

### 3. 多樣化資料輸入
*   **手動下單**：即時手動輸入單筆產品資訊。
*   **CSV 批次匯入**：支援大量訂單一次性匯入，具備**重複編號檢查機制**（自動過濾排隊中及加工中的重複 ID）。

### 4. 視覺化看板 (UI/UX)
*   **即時進度條**：視覺化呈現每台機器的加工剩餘時間。
*   **狀態通知**：包含故障呼吸燈特效、優先級警告標籤及深色模式系統日誌。

## 📂 CSV 匯入格式規範

匯入檔案時，請確保 CSV 格式如下（首行為標題列）：

| 名稱 (Name) | 優先級 (Priority) | 工時 (Time) |
| :--- | :--- | :--- |
| Job_001 | 1 | 15 |
| Job_002 | 5 | 10 |
| Job_003 | 2 | 20 |

> **提示**：系統會自動跳過重複的編號，並在日誌中顯示跳過的筆數。

## 🚀 如何執行

1.  下載專案資料夾。
2.  直接使用瀏覽器（Chrome / Edge / Firefox）開啟 `index.html` 檔案。
3.  開始在「手動下單系統」中輸入資料，或匯入範例 CSV 檔案。

---

## 🧠 開發邏輯簡述 (Code Architecture)

*   **Machine Class**: 負責處理機台自身狀態（閒置、工作中、故障）及倒數邏輯。
*   **Job Class**: 封裝產品屬性，包含加工需求與優先等級。
*   **Main Loop**: 使用 `setInterval` 每秒驅動一次全廠心跳，執行「檢查完工 -> 異常偵測 -> 自動派工 -> 畫面渲染」的循環。
